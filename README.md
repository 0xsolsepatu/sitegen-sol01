## How it works

`solve.js` (Node 22, standard library only, dependency-free ES module)
reimplements makefun-site 1.0.0's build — its front matter, template
dialect, Markdown subset, slug rule and build report — with the same output
byte for byte, faster:

- **Fused lex + render Markdown** — one pass instead of lex-then-render.
- **Run-buffered escaping** and **cached slugify** — no repeated work per
  page.
- **`wordsOf` / cards computed once** per page instead of per template use.
- Templates are compiled once per case; `+=` string building beat
  array-join for templates here.

`main.ts` is the kit's driver, verbatim: it reads every case from
`/input/cases.json`, answers each with `run`, and writes
`/output/answers.json`.

## Verification

- Practice set (3 cases, 276 / 350 / 509 output paths): **3/3 byte-exact**
